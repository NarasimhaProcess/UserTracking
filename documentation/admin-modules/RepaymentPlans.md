# Repayment Plans Management

This document describes the repayment plans management section, nested under the Configuration tab within the Admin screen.

## Overview
This section allows administrators to define and manage various repayment plans for customers.

## Functionality
*   **View Repayment Plans:** Displays a list of defined repayment plans.
*   **Add New Plan:** Create new repayment plans with details like name, frequency (weekly, monthly, etc.), periods, base amount, repayment per period, advance amount, and late fees.
*   **Edit/Delete Plans:** Modify existing repayment plan details or remove them.
