# Group Management

This document describes the group management section within the Admin screen.

## Overview
This section allows administrators to create and manage user groups, assigning users and areas to them.

## Functionality
*   **View Groups:** Displays a list of existing groups.
*   **Add New Group:** Create new groups with a name and description.
*   **Assign Areas:** Link groups to specific geographical areas.
*   **Assign Users:** Add users to groups.
*   **Edit/Delete Groups:** Modify group details or remove them.
