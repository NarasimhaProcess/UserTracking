# Users Management

This document describes the user management section within the Admin screen.

## Overview
This section allows administrators to view, manage, and update user accounts, including roles and location tracking status.

## Functionality
*   **View Users:** Displays a list of all registered users.
*   **User Details:** Shows user email, mobile, and creation date.
*   **Location Status:** Indicates if location tracking is active/inactive for a user.
*   **Location Interval:** Allows setting the frequency (in seconds) for location updates.
*   **Direct Communication:** Provides options to call, SMS, or WhatsApp a user.
*   **Get Directions:** For users with location data, provides a link to Google Maps directions.
*   **Role Management (Superadmin only):** Superadmins can change user roles (user, admin, superadmin, customer).
*   **Delete User (Superadmin only):** Superadmins can delete user accounts.
