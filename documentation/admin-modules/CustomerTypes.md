# Customer Types Management

This document describes the customer types management section, nested under the Configuration tab within the Admin screen.

## Overview
This section allows administrators to define and manage different categories or types of customers.

## Functionality
*   **View Customer Types:** Displays a list of defined customer types.
*   **Add New Type:** Create new customer types with a name and description.
*   **Edit/Delete Types:** Modify existing customer type details or remove them.
